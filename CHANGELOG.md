# Changelog

## [1.0.0] - 2026-11-03

### Added
- Модуль калькулятора `calculator.py`: додавання, віднімання, множення та ділення з обробкою ділення на нуль.
- Модуль конвертації температур `converter.py`.
- Модуль конвертації одиниць `unit_converter.py`.
- Генератор паролів `password_gen.py`.
- Файл `README.md` з описом проєкту, структурою, інструкціями зі встановлення та запуску.
- Файл `.gitignore` для службових файлів Python та редактора.
- Використання Git-гілок і GitHub Pull Requests для командної роботи.

### Changed
- Покращено документацію проєкту та форматування `.gitignore`.
- Виправлено команду клонування репозиторію в `README.md`.
